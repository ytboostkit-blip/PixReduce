# PixReduce

PixReduce is a free, browser-based image utility website for compressing, resizing, aligning, and cropping images.

## Live Website

https://pixreduce.ytboostkit.workers.dev/

## Features

- Image Compressor
- Image Resizer
- Image Alignment
- Image Cropper
- Free Crop
- Passport Size Crop Presets
- Stamp Size Crop Presets
- Aspect Ratio Presets
- Zoom and Rotation Controls
- Live Image Preview
- JPG, PNG and WebP support
- Drag and Drop support
- Browser-based image processing
- No image upload required
- Mobile responsive design
- Dark and Light mode

## Privacy

Images are processed directly in the user's browser. Images do not need to be uploaded to a server for processing.

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
- Google Analytics 4
- Cloudflare Workers
